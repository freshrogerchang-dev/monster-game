# 冰水特攻隊 Monster Game

第一人稱固定站位的 3D 體感水槍射擊遊戲。轉動手機改變視角，按住畫面噴水；殭屍會逐步逼近，碰到玩家就會扣血。

- 小孩版：可愛怪物、較慢速度、較低傷害、較容易冰凍。
- 成人版：陰暗場景、更多敵人、較快速度與較高傷害；武器有突擊步槍、狙擊步槍與火焰槍（按「換」按鈕輪流切換，鍵盤 1／2／3 直接選，按住射擊鍵噴火，敵人會著火持續受傷，火焰也會融化冰凍）。

## 啟動

直接開啟 `index.html`，或在本資料夾執行：

```powershell
npm start
```

瀏覽器開啟 `http://127.0.0.1:4188`。

## 操作

- 手機：按下「啟動水槍」並允許動作與方向權限；轉動手機即可環視場景。
- 射擊：按住遊戲畫面持續噴水，將準星對準殭屍累積冰凍值。
- 關卡：六關（夜晚遊樂園、糖果森林、冰雪村莊、夕陽海灘、南瓜墓園、月球基地），每關三波，最後一關有大魔王；過關會解鎖下一關並記住進度。
- 道具：場上會出現發光道具，用水柱噴到即可獲得（超級水柱、冰凍炸彈、補血、殭屍變慢、泡泡護盾、分數加倍、時間暫停）。
- 音效：右上角 🔊 按鈕可開關音效。
- 桌機備援：按住滑鼠噴水，拖曳滑鼠改變視角。
