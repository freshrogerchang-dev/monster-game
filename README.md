# 冰水特攻隊 Monster Game

第一人稱固定站位的 3D 體感水槍射擊遊戲。轉動手機改變視角，按住畫面噴水；殭屍會逐步逼近，碰到玩家就會扣血。

## 線上遊玩

https://freshrogerchang-dev.github.io/monster-game/

## 啟動

直接開啟 `index.html`，或在本資料夾執行：

```powershell
npm start
```

瀏覽器開啟 `http://127.0.0.1:4188`。

## 操作

- 手機：按下「啟動水槍」並允許動作與方向權限；轉動手機即可環視場景。
- 射擊：按住遊戲畫面持續噴水，將準星對準殭屍累積冰凍值。
- 道具：場上會出現發光道具，用水柱噴到即可獲得（超級水柱、冰凍炸彈、補血、殭屍變慢）。
- 桌機備援：按住滑鼠噴水，拖曳滑鼠改變視角。
